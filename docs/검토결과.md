### 문서 변환

- **HWP 탭(코드 9)을 1 WCHAR 로 처리해 탭 뒤 본문이 유실·깨짐 (extract.py:170)** — _HWP_SINGLE_CTRL 을 스펙대로 {0, 10, 13, 24~31} 로 고쳤습니다. 이제 탭(9)은 공백 하나를 낸 뒤 16바이트를 건너뛰고, 코드 0 은 2바이트만 건너뜁니다. 기존 tests/test_ingest.py 의 _para_text_payload 는 탭을 2바이트로 만들어 잘못된 동작을 정답으로 고정하고 있었습니다. 탭을 8 WCHAR(0x0009 + 정보 6글자 + 0x0009)로 만들도록 고쳤습니다. 회귀 테스트로 탭 폭 0, 4000, 0x2000 일 때 '이름 홍길동 대위' 가 그대로 나오는지와 코드 0 이 1글자로 처리되는지를 넣었습니다.
- **HWPX hp:t 혼합 콘텐츠의 자식 요소 tail 텍스트 유실 (extract.py:124, 146)** — _hwpx_t_text 를 새로 두어 hp:t 의 text, 자식 요소, 각 자식의 tail 을 문서 순서대로 잇습니다. tab, lineBreak, nbSpace, fwSpace 는 공백으로 바꾸고 markpen 같은 표시 요소는 tail 만 남깁니다. 일반 문단, 표를 포함한 문단(예전 146행), 표 셀 모두 _hwpx_para_text 한 함수로 처리하도록 묶었습니다. 회귀 테스트는 탭, 형광펜으로 시작하는 문단, 줄바꿈, 표 앞 문단과 셀 경우를 다룹니다.
- **출력 파일명(stem) 충돌로 같은 실행 안의 문서가 건너뛰어지거나 덮어써짐 (convert.py:200)** — ingest_paths 가 이번 실행에서 배정한 출력 이름(대소문자 무시)과 그 원본을 기록합니다. _unique_name 은 이름이 이미 배정되었을 때 다음 순서로 고유한 이름을 정합니다. 앞 원본과 폴더가 다르면 상위 폴더명을 붙이고(2대대_경계지침.md), 폴더가 같으면 확장자를 붙입니다(보고서_txt.md). 그래도 겹치면 _2, _3 을 붙입니다. 이 충돌 검사는 '이미 있음' 이나 덮어쓰기 판정보다 먼저 하고, dry_run 에서도 같은 이름이 배정됩니다. 같은 파일을 두 번 넘기면 한 번만 변환합니다. 다시 실행해도 같은 이름이 나와 skip/overwrite 가 기대대로 동작하는지 테스트로 확인했습니다.
- **PDF 쪽 번호 정규식이 숫자만 있는 모든 줄을 삭제 (extract.py:293)** — merge_pdf_lines 에서 무조건 지우는 대상을 '- 3 -' 처럼 양쪽에 하이픈이 붙은 형태로만 좁혔습니다. 새 함수 strip_pdf_page_numbers 가 extract_pdf 에서 쪽마다 맨 첫 줄과 맨 끝 줄만 검사해 쪽 번호를 지웁니다. 대상은 숫자, 'n / m', 'p. n', 'n쪽' 형태입니다. 장식 없는 숫자는 쪽 수+100 이하일 때만 쪽 번호로 보므로 '2025' 같은 연도는 남습니다. 쪽 중간의 '1', '12', '2025', '3/4' 는 보존됩니다. 기존 test_extract_pdf 는 쪽 중간의 '2' 를 쪽 번호로 보고 지우는 동작을 기대하고 있었습니다. 그래서 '2' 를 쪽 마지막 줄로 옮기도록 테스트를 수정했습니다.
- **_CHAPTER 가 단위 글자 뒤 경계를 요구하지 않아 본문 문장을 장 제목으로 오인 (convert.py:19)** — _CHAPTER 가 단위 글자 뒤에 공백과 제목을 요구하도록 바꾸고 _is_chapter 를 추가했습니다. 나머지가 '제N조/항/호' 로 시작하거나 문장 종결(다/음/함/됨/임, 마침표)로 끝나면 장 제목에서 제외합니다. '제2장의 규정을 준용한다.', '제3장비 점검', '제3절 제12조부터 … 준용한다.' 는 더 이상 장 제목이 되지 않습니다.
- **'제N조의M' 의 가지번호를 버려 섹션명이 '제N조' 로 생성 (convert.py:115)** — _ARTICLE 이 가지번호를 그룹 2로 캡처하고, 섹션명 head 에 '의{M}' 을 붙입니다. 예: '제1장 총칙 › 제5조의2(정의의 특례)'. 라벨과 본문 그룹 번호도 이에 맞춰 3·4·5 로 옮겼습니다.
- **_ARTICLE 이 '조' 뒤 경계를 요구하지 않아 '제N조에 따라…' 문장이 새 조문이 됨 (convert.py:18)** — '조'(와 '의N') 바로 뒤가 공백, 괄호, 줄 끝일 때만 조문으로 봅니다. _match_article 을 새로 두었는데, 라벨 없이 '및/또는/내지/부터/까지/제N항' 같은 참조 표현이 이어지면 조문에서 제외합니다. _detect_mode 와 _structure 모두 이 함수를 씁니다. '제11조제2항에 따른…', '제5조 및 제6조에 따라…' 는 본문으로 남고, '제7조 삭제' 처럼 라벨 없는 진짜 조문은 계속 인식됩니다.
- **번호 제목 판정이 날짜·수치 줄을 섹션 제목으로 오인 (convert.py:21)** — _is_numbered_heading 에 두 가지 제외 조건을 넣었습니다. 하나는 날짜 줄(^\d{2,4}\.\s*\d{1,2}\. …)이고, 다른 하나는 'N.N' 바로 뒤에 단위(km, kg, m, %, 시간 등)가 오는 줄입니다. 영문 약어로 시작하는 정상 제목(예: '2.1 GPS 점검')은 그대로 제목으로 인식됩니다.
- **HWPX 머리말·꼬리말·각주 텍스트가 호스트 문단에 합쳐짐 (extract.py:123)** — header, footer, footNote, endNote, hiddenComment, secPr 하위는 문단 글자 수집, 표 셀 수집, visit 재귀 어디에서도 순회하지 않습니다. 이제 머리말이 붙은 첫 문단이 제목으로 쓰여도 오염되지 않고, 각주도 조문 본문에 섞이지 않습니다. 표를 포함한 문단 안의 머리말이 따로 출력되던 경로도 막았고, 모듈 docstring 도 고쳤습니다.
- **HWP UTF-16 서로게이트 쌍을 chr() 로 낱개 변환해 ingest 전체가 UnicodeEncodeError 로 중단 (extract.py:247)** — _decode_para_text 가 글자 바이트를 모아 bytes.decode('utf-16-le', errors='replace') 로 한 번에 풉니다. '𠀋' 같은 확장 한자도 한 글자로 나옵니다. 또 convert.py 의 mkdir 과 write_text 를 파일별 try 블록 안으로 옮겼습니다. 저장에 실패하면 '저장하지 못했습니다 (...)' 오류를 해당 파일 결과로만 남기고 다음 파일 변환을 계속합니다.
- **.md 입력의 front matter 를 본문으로 읽어 재변환 시 제목이 '---' 가 됨 (extract.py:30)** — .md/.txt 는 parse_front_matter 로 머리말을 떼고 본문만 문단으로 나눕니다. 새 함수 read_front_matter 가 기존 메타를 돌려주고, convert_file 이 이를 ConvertedDoc.meta(새 선택 필드)에 담습니다. to_markdown 은 인자로 새 값을 주지 않은 category, effective_date, version, tags 와 원본 source_file, 기타 키를 보존합니다. 제목은 --title, 머리말 title, 추정 순으로 정합니다. 제목으로 쓴 '# 제목' 줄은 본문에서 빠지므로 '# 제목' 이 두 번 나오지 않습니다. _guess_title 은 구분선이나 'key: value' 꼴 줄을 제목 후보에서 뺍니다.
- **중첩 표의 행이 바깥 셀 텍스트와 별도 행으로 중복 추출 (HWPX, DOCX) (extract.py:134)** — HWPX 와 DOCX 모두 표에 직접 속한 tr/tc 만 돌도록 바꿨습니다. 셀 글자에는 중첩 표 안의 문단을 넣지 않고, 중첩 표는 그 행 다음에 재귀로 따로 출력합니다. DOCX 는 sdt 로 감싼 행과 셀도 풀어서 처리합니다. 결과는 ['| 외부A |  |', '| 내부1 | 내부2 |'] 처럼 중복이 없습니다.
