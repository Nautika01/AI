# 군사보안 기본 수칙 (샘플)

## 보안의 3대 원칙
1. **알 필요성(Need-to-know)**: 직무 수행에 필요한 사람에게만 정보를 제공한다.
2. **최소 권한**: 시스템·자료 접근 권한은 임무에 필요한 최소 범위로 부여한다.
3. **분리 보관**: 비밀 자료는 인가된 망·장비·보관함에서만 취급하며, 평문망·개인 장비로 옮기지 않는다.

## 휴대전화·SNS 사용
- 부대 내 지정 구역에서는 촬영·녹음 기능을 사용하지 않는다.
- 부대 위치, 훈련 일정, 장비 사진, 부대 마크가 식별되는 사진을 SNS에 올리지 않는다.
- 위치 태그·메타데이터(EXIF)가 포함된 사진은 외부 공유 전에 제거한다.
- 단체 대화방에서 작전·훈련 관련 내용을 논의하지 않는다.

## 사이버 보안
- 업무망과 인터넷망을 분리 운용하고, 인가되지 않은 이동식 저장매체(USB)를 연결하지 않는다.
- 출처가 불분명한 이메일 첨부파일·링크를 열지 않는다. 의심 메일은 보안 담당자에게 신고한다.
- 비밀번호는 10자 이상, 영문·숫자·특수문자를 조합하고 주기적으로 변경한다.
- 생성형 AI 서비스 등 외부 서비스에 비밀·대외비 자료, 개인정보, 부대 식별정보를 입력하지 않는다.

## 문서 보안
- 비밀 문서는 등급 표기, 관리 번호, 보관 책임자를 명확히 하고 열람 기록을 남긴다.
- 폐기 시 세단 또는 소각 등 승인된 방법을 사용한다.
- 자리를 비울 때 책상 위 문서를 정리하고 화면을 잠근다(클린 데스크·클린 스크린).

## 보안 사고 대응
보안 사고(분실·유출·해킹 의심)를 인지하면 **즉시 보고**가 최우선이다. 은폐·지연은 피해를 키운다. 보고 후에는 증거 보존(장비 전원 유지, 로그 보관)을 하고 보안 담당관의 지시를 따른다.
