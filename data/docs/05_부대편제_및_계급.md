# 부대 편제와 계급 체계 (샘플)

## 육군 부대 편제(일반적 규모)
| 제대 | 통상 규모 | 지휘관 |
|---|---|---|
| 분대 | 8~12명 | 하사·중사(분대장) |
| 소대 | 3~4개 분대, 30~40명 | 소위·중위(소대장) |
| 중대 | 3~4개 소대, 100~150명 | 대위(중대장) |
| 대대 | 3~5개 중대, 400~800명 | 중령(대대장) |
| 연대/여단 | 3~5개 대대 | 대령·준장 |
| 사단 | 3~4개 여단, 1만여 명 | 소장 |
| 군단 | 2~5개 사단 | 중장 |
규모는 병과·편성 기준에 따라 달라지며, 위 수치는 이해를 돕기 위한 개략치다.

## 계급 체계
- **병**: 이병 → 일병 → 상병 → 병장
- **부사관**: 하사 → 중사 → 상사 → 원사
- **준사관**: 준위
- **위관 장교**: 소위 → 중위 → 대위
- **영관 장교**: 소령 → 중령 → 대령
- **장성**: 준장 → 소장 → 중장 → 대장

## 참모 편성 (일반참모)
- 1처/과(G1·S1): 인사
- 2처/과(G2·S2): 정보
- 3처/과(G3·S3): 작전·교육훈련
- 4처/과(G4·S4): 군수
- 5처/과(G5·S5): 민사·계획
- 6처/과(G6·S6): 통신·정보체계
G는 사단급 이상, S는 여단·대대급 참모를 가리킨다.

## 지휘 관계 용어
- **배속**: 부대를 다른 부대에 일시적으로 소속시켜 지휘·행정·군수 책임을 넘기는 것
- **작전통제(OPCON)**: 특정 임무·기간에 한해 작전상 지휘권만 부여
- **전술통제(TACON)**: 기동·화력 등 세부 전술 지시 권한만 부여
- **직접지원(DS)·일반지원(GS)**: 지원 부대가 특정 부대를 우선 지원하는지, 전체를 지원하는지 구분
