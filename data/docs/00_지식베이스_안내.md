# 지식 베이스 안내

## 목적
이 디렉터리의 문서는 국방 특화 AI 비서의 로컬 지식 베이스(RAG)에 적재되는 **샘플·교육용 참고 자료**다. 공개된 일반 군사 상식과 보편적인 절차를 요약한 것이며, 특정 부대의 실제 규정·작전 자료가 아니다. 실제 운용 시에는 소속 부대에서 승인한 비밀 등급 이하의 규정·교범·지침으로 교체한다.

## 문서 작성 규칙
- 파일 형식: Markdown(.md) 또는 텍스트(.txt), UTF-8.
- 첫 줄 `# 제목`이 문서 제목이 되고, `## 소제목` 단위로 검색 청크가 나뉜다.
- 한 섹션은 1,200자 이내를 권장한다. 길면 문단 단위로 자동 분할된다.
- 비밀·대외비 표기가 있는 자료는 적재하지 않는다. 이 비서는 일반(평문) 자료만 다루도록 설계되었다.

## 문서 갱신
문서를 추가·수정한 뒤 비서를 재시작하면 자동으로 다시 색인된다. 별도의 벡터 DB나 외부 임베딩 서비스는 필요하지 않다.
