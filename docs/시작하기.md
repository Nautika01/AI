# 시작하기: 설치부터 첫 대화까지

GitHub에서 코드를 내려받아 국방 특화 AI 비서를 처음 실행하기까지의 전 과정입니다. Windows(PowerShell) 기준으로 쓰고, Mac·Linux에서 다른 부분은 따로 표시했습니다. 전체 소요 시간은 10분 안팎입니다.

---

## 0. 준비물

| 항목 | 확인 방법 | 없으면 |
|---|---|---|
| Git | PowerShell에 `git --version` | [git-scm.com](https://git-scm.com) 에서 설치 |
| Python 3.10 이상 | `python --version` | [python.org](https://www.python.org/downloads) 에서 설치. 설치 화면에서 **"Add Python to PATH"** 를 반드시 체크 |
| Anthropic API 키 | – | 아래 2단계 참고 |

설치 직후에는 PowerShell을 **새로 열어야** 명령이 인식됩니다.

---

## 1. 코드 내려받기 (클론)

PowerShell을 열고 한 줄씩 입력합니다.

```powershell
cd ~
mkdir Projects
cd Projects
git clone https://github.com/Nautika01/AI.git
cd AI
```

- `cd ~` : 내 홈 폴더(`C:\Users\사용자이름`)로 이동
- `mkdir Projects` : 작업 폴더 생성 (이미 있으면 오류가 나도 무시하고 다음 줄 진행)
- `git clone …` : GitHub의 코드를 복사해 `AI` 폴더 생성
- `cd AI` : 그 폴더로 이동. **이후 모든 명령은 이 폴더 안에서** 실행합니다.

> ⚠️ `Permission denied` 오류가 나면 `C:\Windows\System32` 같은 시스템 폴더에서 실행한 것입니다. `cd ~` 부터 다시 하십시오.

---

## 2. API 키 발급

1. [console.anthropic.com](https://console.anthropic.com) 접속 후 가입·로그인
2. 왼쪽 메뉴 **API Keys** → **Create Key** → 이름 입력(예: `defense-ai`)
3. `sk-ant-` 로 시작하는 키가 **한 번만** 표시됩니다. 즉시 복사해 둡니다.
4. 왼쪽 메뉴 **Billing** 에서 결제 수단 등록 후 소액 충전(시험용은 5달러면 충분)

키는 비밀번호와 같습니다. 채팅·코드·GitHub에 붙여 넣지 마십시오.

---

## 3. 설정 파일 만들기

```powershell
copy .env.example .env
notepad .env
```

Mac·Linux:
```bash
cp .env.example .env
nano .env      # 또는 open -e .env
```

메모장이 열리면 두 번째 줄을 찾아 `=` 뒤에 키를 붙여 넣습니다. 따옴표·공백 없이:

```
ANTHROPIC_API_KEY=sk-ant-api03-복사한키전체
```

나머지 줄은 그대로 둡니다. **Ctrl+S** 저장 후 닫습니다.

`.env` 파일은 `.gitignore` 에 포함되어 있어 GitHub에 올라가지 않습니다.

---

## 4. 설치

```powershell
pip install -e ".[server,dev]"
```

따옴표까지 그대로 입력합니다. 1~2분 뒤 `Successfully installed …` 가 나오면 완료입니다.

- `pip` 을 찾을 수 없다고 나오면 Python 설치 시 PATH 등록이 안 된 것입니다. Python을 다시 설치하며 "Add Python to PATH" 를 체크하고 PowerShell을 새로 엽니다.
- Mac·Linux에서 `pip` 이 없으면 `pip3` 또는 `python3 -m pip` 으로 바꿔 입력합니다.

---

## 5. 실행

```powershell
defense-ai
```

`defense-ai` 명령을 찾을 수 없으면 대신:

```powershell
python -m defense_assistant
```

성공하면 이런 화면이 나옵니다.

```
국방 특화 AI 비서 (모델 claude-opus-5-5, 추론 high, 허용 등급 대외비)
지식 베이스 46개 청크 적재. /help 로 명령을 확인하십시오.

▶
```

`▶` 뒤에 질문을 입력하고 Enter. 예:

```
▶ SITREP 항목이 뭐야?
▶ 071430IOCT26 를 줄루 시간으로 바꿔 줘
▶ SPOTREP 양식 만들어 줘. 규모는 차량 3대, 시각 071430IOCT26
▶ 거수자 발견 시 조치 절차 알려줘
```

대화 중 명령:

| 명령 | 기능 |
|---|---|
| `/help` | 도움말 |
| `/reset` | 대화 기록 초기화 |
| `/docs 검색어` | 지식 베이스만 직접 검색 |
| `/status` | 현재 설정·세션 상태 |
| `/exit` | 종료 |

---

## 6. 다음에 다시 실행할 때

설치는 한 번이면 됩니다. 이후에는 두 줄만 입력합니다.

```powershell
cd ~\Projects\AI
defense-ai
```

GitHub의 코드가 바뀌었을 때 최신으로 맞추려면:

```powershell
cd ~\Projects\AI
git pull
pip install -e ".[server,dev]"
```

## 7. 자주 나오는 문제

| 화면 메시지 | 원인 | 해결 |
|---|---|---|
| `API 인증 정보가 없습니다` | `.env` 저장이 안 됐거나 키 앞뒤에 공백 | `notepad .env` 로 다시 확인 |
| `API 인증에 실패했습니다` | 키가 틀렸거나 삭제됨 | 콘솔에서 새 키 발급 후 `.env` 수정 |
| `요청 한도를 초과했습니다` / 결제 관련 | 잔액 부족 | 콘솔 Billing 에서 충전 |
| `입력에서 … 등급 표기가 감지되었습니다` | 비밀·대외비 표기 차단 (정상 동작) | 표기를 빼고 일반 질문으로 |
| `ModuleNotFoundError` | 설치가 안 됐거나 다른 폴더에서 실행 | `cd ~\Projects\AI` 후 4단계 재실행 |
| 한글이 깨져 보임 | PowerShell 인코딩 | `chcp 65001` 입력 후 재실행, 또는 Windows Terminal 사용 |

---

## 8. 선택 사항

- **HTTP 서버로 띄우기**: `defense-ai serve --port 8000` → 브라우저에서 `http://127.0.0.1:8000/docs` 로 API 문서 확인
- **지식 베이스 교체**: `data\docs\` 안의 `.md` 파일을 부대 승인 평문 자료로 바꾸고 재실행
- **설정 변경**: `.env` 에서 `DAI_MODEL`, `DAI_EFFORT`, `DAI_MAX_CLASSIFICATION` 등 수정. 항목 설명은 `README.md` 참고
- **테스트 실행**: `pytest` (API 키 없이도 동작)
